# Спецификация протокола

Транспорт: UDP, порт 9050. Порядок байт: **big-endian** (сетевой).
Максимальный размер пакета — 65 535 байт; используемые пакеты значительно меньше.

## Заголовок (9 байт)
| Смещение | Размер | Поле | Тип | Описание |
|---|---|---|---|---|
| 0 | 1 | PacketType | byte | Тип пакета |
| 1 | 2 | SequenceNumber | uint16 | Порядковый номер, растёт на стороне клиента; ответ сервера копирует номер запроса |
| 3 | 2 | PayloadSize | uint16 | Длина данных после заголовка |
| 5 | 4 | Checksum | uint32 | CRC32 всего пакета, вычисленный при Checksum = 0 |

## Типы пакетов
| Код | Имя | Направление | Payload |
|---|---|---|---|
| 1 | Auth | C → S | `[uint8 loginLen][login UTF-8][uint8 passLen][password UTF-8]` |
| 2 | AuthResult | S → C | `uint8`: 1 — успех, 0 — отказ |
| 3 | Movement | C → S | `float X, float Y, float Z` (12 байт) |
| 4 | PositionUpdate | S → C | `float X, float Y, float Z` (12 байт) |
| 5 | Shoot | C → S | `uint8 weaponId` |
| 6 | ShootResult | S → C | `uint8 weaponId, uint8 hit` |
| 255 | Error | S → C | пусто |

## Правила обработки
- Пакет с неверной длиной или CRC сервер молча отбрасывает.
- Movement и Shoot принимаются только от авторизованных клиентов, иначе ответ Error.
- Клиент ждёт ответ 2 секунды (таймаут), повторная отправка не реализована.

## Пример пакета Shoot (weaponId = 1)
Заголовок (9 байт) + payload `01`; всего 10 байт.
